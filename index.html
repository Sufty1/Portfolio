About Me

I'm a sophomore at Duke University studying Electrical and Computer Engineering, with a focus on building and understanding complex systems, from embedded hardware to large-scale infrastructure.

Born in Mexico and raised in the U.S. since age 14, I bring a perspective shaped by adaptability, discipline, and curiosity. My work spans hands-on engineering and research, including developing microrobotics systems and designing hardware/software projects that integrate computation with the physical world.

I'm especially interested in how engineering can power the next generation of technologies in energy, robotics, and beyond.

Projects

001 Microrobotics

MXene Vapor-Propelled Microrobot

Identified asymmetric vapor jetting as the mechanism behind controllable rotational flight in an untethered microrobot — fabricated MXene composite films, characterized propulsion under NIR laser irradiation, and confirmed stability through systematic experimental testing.

Material Fabrication NIR Laser Systems Experimental Testing Data Analysis
002 Digital Logic

16-bit RISC CPU

Built and verified a complete single-cycle 16-bit RISC processor in Logisim — designed the custom ISA, ALU, register file, and control unit from scratch, then validated correct execution by running hand-written assembly programs including Fibonacci generation and prime detection.

Logisim Evolution Assembly Digital Logic Design
003 Embedded Systems

ESP32 Open-Loop DC Motor Speed Controller

Diagnosed and corrected ESP32 ADC non-linearity — recalibrated the PWM duty-cycle mapping to eliminate control discontinuities at high duty cycle. The system integrates potentiometer input, SSD1306 OLED telemetry display, and a bidirectional Bluetooth Serial interface for remote speed override.

ESP32 C / C++ L298N H-Bridge SSD1306 OLED Bluetooth SPP

004 Embedded Systems

Autonomous CX-Bot

Programmed an Arduino-based autonomous robot to navigate via QTI line sensors and coordinate with peer units over XBee wireless — implementing the inter-unit communication protocol and sensor fusion logic in C++.

Arduino C / C++ XBee QTI Sensors
005 Algorithms

Highway Route Finder

Implemented Dijkstra's shortest-path algorithm in Java over a large highway graph dataset — applied a priority queue for O(E log V) performance and modeled the road network as a weighted graph with clean OOP separation between routing logic and data I/O.

Java OOP Graph Algorithms File I/O
006 Hackathon

Forage — Gamified Nature Exploration App

Built a full-stack mobile app in 24 hours at HackDuke 2026 where users photograph plants and animals, triggering GPT-4o Vision to identify the species and auto-generate a fact card with habitat, ecological relevance, and conservation notes. Engineered a gamification and live expedition tracking system with a points engine featuring diminishing returns, rare species bonuses, and badge awards, alongside Auth0 PKCE authentication and a Supabase PostgreSQL backend.

React Native Expo TypeScript Supabase OpenAI GPT-4o Auth0
